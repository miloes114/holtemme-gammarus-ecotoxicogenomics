# Holtemme research compendium v1.0.1

Version 1.0.1 is a presentation and publication-synchronization update to the Holtemme *Gammarus pulex* ecotoxicogenomics research compendium. Figure 4 now uses an observed-state evidence legend representing the five evidence combinations present in the frozen functional-synthesis data. The Step 06 rendered report, Supplementary Information, author metadata, and publication-facing documentation were synchronized with the submitted manuscript.

Scientific analyses, differential-expression results, functional evidence assignments, semantic-feature counts, WGCNA results, chemistry results, and underlying provenance are unchanged from v1.0.0.
